Sunlit Vault is a bright, top-down gallery heist game: sneak through three wings of the Meridian Gallery, read guard vision cones and sweeping cameras, charge Gleam in the drifting sunbeams, and steal the Sun Opal from the Sun Vault before the alarm meter fills.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: game/index.html and its ES modules under game/ are plain static files.
